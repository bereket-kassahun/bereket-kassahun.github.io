# bereket-kassahun.github.io

Personal portfolio of **Bereket Kassahun** — live at [bereket-kassahun.github.io](https://bereket-kassahun.github.io).

Plain HTML/CSS/JS, no build step. Push to `main` and GitHub Pages serves it.

## Customizing images

- **Your photo** → drop it at `assets/profile.jpg` (square works best). Until then a "BK" monogram shows.
- **Company logos** → drop PNGs into `assets/logos/`:
  `atlas.png`, `oneok.png`, `upwork.png`, `ashewa.png`, `4kbots.png`
  If a file is missing, the site automatically tries the company's favicon, then falls back to initials — so nothing ever looks broken.
- **Résumé** → replace `resume.pdf` to update the download button.
